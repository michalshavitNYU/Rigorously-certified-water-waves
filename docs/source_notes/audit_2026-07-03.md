## Headline finding (CRITICAL, found independently by two agents)

**`cert_arb_trigpoly_to_taylor` (CertificateAxioms.lean:102) is FALSE as stated,
making the axiom system inconsistent.** It quantifies over *arbitrary* smooth
`f : ℝ → ℝ` with no periodicity/boundedness hypothesis, but its conclusion
`IsTaylorSeriesOf ts f a` requires (via `sup_acc`, TaylorSeriesCorrectness.lean:107)
a *global* sup bound `∀ x : ℝ, |iteratedDeriv m f x| ≤ ts.sup_bounds m`.
Instantiating `f := id` (which is `ContDiff ℝ (M+1)`) demands a real bounding `|x|`
over all of ℝ — impossible. So `False` is derivable, and every downstream theorem —
including the headline `residual_bounded_by_certificate` (Main.lean:94) — is
vacuously provable in the current axiom system.

- All actual uses (`y`, `yu`, `Hyu`, `1+Hyu`, `D` inside `cert_arb_residual_TS`)
  are 2π-periodic and bounded, so the *intended* instances are true.
- **Fix (one line):** add `Function.Periodic f (2 * Real.pi)` (or restrict `f` to
  the trig-poly shape of `trigpoly_to_taylor_correct`) to the axiom's hypotheses.
- Until fixed, the "machine-checked" claim for the headline should not be made.
- **FIXED on branch `audit-fixes` (2026-07-03)**: periodicity hypothesis added,
